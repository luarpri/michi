# Michi

Scratch project downloader written in Scratch itself

why? yes (:

## Websites

### Full support
- Scratch
	- Scratch 3 projects (.sb3)
	- Scratch 2 projects (.sb2)
	- Scratch 1 projects (.sb)
- [Scratchbox](https://scratchbox.dev)
- [Zippr](https://www.zipprpj.website/)

### Planned support

- [MistWarp](https://mistwarp.org/)
- [PenguinMod](https://penguinmod.com/)

## Installation

Clone with submodules:

```bash
git clone --recursive https://github.com/luarpri/michi.git
```
Get the sb3:

```bash
python3 blockvine/sb3break.py michi.sb3
```
You should now open the project using any based TurboWarp editor

> [!NOTE]
> You may need TurboWarp Desktop or the scratch mod desktop file equivalent to use the project correctly
> In TW's Desktop you will need to enable "Allow extensions to access any website" in Settings > Desktop settings
